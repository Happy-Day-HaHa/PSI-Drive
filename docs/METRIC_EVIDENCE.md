## 1. 결론 요약

현재 웹사이트의 운전 분석 수치는 **실제 운전자나 실제 차량에서 수집한 값이 아니다.** 고정 시드로 재현할 수 있는 합성 주행 신호와 합성 사건 정답을 이용해 화면과 분석 로직을 검증한 결과다.

웹사이트에서 사용하는 숫자는 다음 네 종류로 구분해야 한다.

1. **합성 계산값**: 생성된 속도·IMU·페달 신호와 T0~T7 정답 마커에서 계산한 값.
2. **PSI 내부 설정값**: 사건 검출, 동기화 목표, 점수 변환을 위해 제품이 임시로 정한 값.
3. **외부 연구 참고값**: NHTSA·FHWA·ISO 자료에서 확인한 연구 또는 설계 수치. PSI 점수에 직접 대입하지 않는다.
4. **화면용 메타데이터**: 사건 날짜·시각과 ID처럼 실제 센서 측정이 아니라 시연을 위해 고정한 값.

따라서 현재 수치로 주장할 수 있는 것은 “동일한 합성 입력에서 동일한 계산 결과가 나온다”까지다. “안전하다”, “사고 가능성이 낮다”, “실제 운전자 평균보다 빠르다” 같은 주장은 할 수 없다.

## 2. 데이터 생성과 추적 경로

```text
고정 시드 6개
  → psi_synth 합성 주행 생성
  → 속도·가속도·페달 압력·발 위치 신호
  → 합성 정답 T0~T7
  → export_web.py 집계
  → pedal-samples.json
  → 대시보드·운전 습관·주행 기록 화면
```

### 2.1 생성 조건

| 항목 | 값 | 출처 |
|---|---:|---|
| 합성 세션 수 | 6개 | `SESSION_SPECS` |
| 고정 시드 | 101, 201, 301, 102, 202, 302 | `SESSION_SPECS` |
| 웹 그래프 표본 간격 | 20ms | `SAMPLE_DT_MS` |
| 제동 평균 곡선 간격 | 25ms | `CURVE_STEP_MS` |
| 제동 평균 곡선 길이 | 1,500ms | `CURVE_LENGTH_MS` |
| 사건 그래프 앞뒤 여유 | 기본 1,000ms | `PADDING_MS` |
| 설정 버전 | v1 | `scoring_config.v1.yaml` |

구현 위치:

- 생성기: `tools/synth/src/psi_synth/export_web.py`
- 생성 결과: `apps/web/src/lib/pedal-samples.json`
- 설정: `config/scoring_config.v1.yaml`
- 화면 변환: `apps/web/src/lib/pedal.ts`, `apps/web/src/lib/event-analysis.ts`

### 3.1 분석 범위와 집계값

| 화면 표시 | 현재 값 | 산식·근거 | 성격 |

| 합성 주행 시간 | 8.9분 | 6개 세션 지속시간 합계 ÷ 60,000 | 합성 계산값 |
| 주의 장면 | 12건 | 합성 시나리오가 가진 위험 사건 전체 수 | 합성 계산값 |
| 급가속 구간 | 1건 | 합성 IMU가 +0.3g 이상인 연속 구간 수 | 내부 기준을 적용한 계산값 |
| 급감속 구간 | 12건 | 합성 IMU가 −0.4g 이하인 사건 수 | 내부 기준을 적용한 계산값 |
| 평균 페달 전환 | 348ms | 12개 주의 장면의 `T4 − T2` 평균 | 합성 계산값 |
| 대표 중첩 장면 | 2건 | 주행 기록에 내보낸 중첩 재생 장면 수 | 합성 계산값 |
| 사건별 평균 반응 점수 | 64점 | 점수가 있는 대표 사건 8건의 평균, 반올림 | 내부 점수 산식 적용값 |

주의 장면 12건과 점수 사건 8건이 다른 이유는 모든 합성 사건을 평균·분포 집계에는 사용하지만, 웹 상세 재생에는 세션별 대표 사건만 내보내기 때문이다.

### 3.2 사건 점수 산식

사건 점수는 아래 세 지표를 각각 0~100점 구간선형 곡선으로 바꾼 뒤 산술평균하고 반올림한다.

| 지표 | 100점 기준 | 0점 기준 | 설정 상태 |
|---|---:|---:|---|
| 인지 후 가속 해제 시작 `T1−T0` | 300ms 이하 | 1,000ms 이상 | 내부 가정 |
| 페달 전환 `T4−T2` | 200ms 이하 | 600ms 이상 | 제품 초기 곡선 |
| 총 제동 반응 `T4−T0` | 700ms 이하 | 1,500ms 이상 | 제품 초기 곡선 |

범위 사이 값은 선형 보간하며 범위 밖은 0점 또는 100점으로 고정한다. 이 산식은 Phase 4 확정 전 임시 산식이다.

화면의 상태 문구는 다음과 같이 코드에 고정돼 있다.

| 점수 구간 | 화면 문구 | 근거 상태 |
|---|---|---|
| 70점 미만 | 주의 / 높은 주의 | UI 초기 분류, 외부 검증 없음 |
| 70점 이상 85점 미만 | 살펴보기 | UI 초기 분류, 외부 검증 없음 |
| 85점 이상 | 정보 | UI 초기 분류, 외부 검증 없음 |

이 구간을 안전·위험 판정 기준으로 인용해서는 안 된다.

### 4.2 페달 사용 시간 비율

| 상태 | 현재 값 | 정의 |
|---|---:|---|
| 가속 | 78.9% | 이동 중 가속 ON·브레이크 OFF |

반올림 전 시간 합계를 분모로 사용하고 최종 비율을 소수점 첫째 자리로 반올림한다.

### 4.3 분포 그래프

#### 가속 페달 압력 분포

| 압력 구간 | 시간 비율 |
|---|---:|
| 0~10% | 2.37% |
| 10~15% | 2.36% |
| 15~20% | 45.56% |
| 20~25% | 33.57% |
| 25~30% | 11.55% |
| 30~35% | 3.77% |
| 35~40% | 0.07% |
| 40~60% | 0.09% |
| 60~100% | 0.66% |

화면의 “주로 15~20% 압력”은 가장 비율이 높은 구간이 45.56%이기 때문에 표시된다. “40% 이상 0.8%”는 0.09%와 0.66%의 합 0.75%를 소수점 첫째 자리로 반올림한 값이다.

#### 제동당 최대 압력 분포

| 최대 압력 구간 | 사건 수 |
|---|---:|
| 0~20% | 0건 |
| 20~40% | 8건 |
| 40~60% | 3건 |
| 60~80% | 5건 |
| 80~100% | 4건 |

화면의 “60% 이상 9회”는 5건과 4건의 합이며, “40% 이하 8회”는 0건과 8건의 합이다. ‘강한’과 ‘부드러운’이라는 표현은 이 화면의 설명용 구간 명칭이며 안전성 검증 결과가 아니다.

#### 페달 전환 시간 분포

| 전환 시간 | 사건 수 |
|---|---:|
| 200ms 이하 | 0건 |
| 200~300ms | 2건 |
| 300~400ms | 6건 |
| 400~500ms | 4건 |
| 500ms 초과 | 0건 |

화면의 “400ms 초과 4건”은 마지막 두 구간의 합이다. 400ms는 분포를 설명하기 위한 구간 경계이며 검증된 안전 경계가 아니다.

### 4.4 제동 곡선 비교

브레이크 접촉 T4를 0ms로 맞춘 뒤 25ms 간격으로 압력 곡선을 평균한다. 접촉 후 250ms 시점의 합성 평균은 다음과 같다.

| 구분 | 250ms 시점 평균 압력 | 화면 반올림값 |
|---|---:|---:|
| 주의 장면 | 52.2% | 52% |
| 일상 감속 | 6.3% | 6% |

이는 합성 시나리오 두 집단의 신호 차이를 보여줄 뿐 실제 운전자 집단 차이를 의미하지 않는다.

## 5. 사건·주행 기록 화면 사용값

### 5.1 공통 산식

| 화면 값 | 산식·정의 |
|---|---|
| 시작·종료 속도 | 사건 시작·종료 표본의 `speed_mps × 3.6` |
| 최대 가속 | 사건 구간 IMU의 양의 최댓값 ÷ 중력가속도 |
| 최대 감속 | 사건 구간 IMU의 음의 최솟값 절댓값 ÷ 중력가속도 |
| 최대 제동 압력 | 사건 구간 `brake_pct` 최댓값 |
| 중첩 시간 | 두 페달 ON 구간 종료−시작 |
| 타력 시간 | 가속 OFF부터 브레이크 ON까지 |
| 변화 강도 `g/s` | 인접 20ms IMU 표본 차이 절댓값 ÷ 0.02초의 최댓값 |
| 영상 시점 불확실성 | 30fps 한 프레임 33.3ms의 절반 ≈ ±16.7ms, 화면에는 ±17ms |

### 5.4 날짜·시각·위치

사건 날짜와 시각은 센서에서 수집한 값이 아니다.

- 기준일은 생성기 상수 `2026-11-01`이다.
- 시각은 `08:38, 18:12, 08:21, 17:47, 07:55, 19:03`을 반복 배정한다.
- 사건 ID는 속도와 유형으로 정렬한 후 E01부터 순서대로 부여한다.
- 위치는 실제 GNSS 값이 없으므로 화면에 “합성 시나리오 · 위치 미수집”으로 표시한다.

날짜와 시각은 화면 동작을 확인하기 위한 시연용 메타데이터이며 주행 증거로 사용할 수 없다.

## 6. PSI 내부 설정값과 근거 상태

| 설정 | 현재 값 | 사용 목적 | 근거 상태 |
|---|---:|---|---|
| 페달 ON | 5% 이상 | 접촉 시작 후보 | 제품 초기 설정 |
| 페달 OFF | 2% 이하 | 접촉 종료 후보 | 제품 초기 설정 |
| 디바운스 | 20ms | 순간 노이즈 제거 | 제품 초기 설정 |
| 압력 필터 | Butterworth 4차, 20Hz, zero-phase | 압력 신호 평활화 | 요구사항 초기 설정 |
| T5 | 사건 최대 압력의 80% | 제동력 상승 시점 | 제품 정의 |
| T6 | −0.1g 이하 | 차량 감속 시작 | 제품 정의 |
| 급가속 | +0.3g 이상 | 후보 사건 탐지 | 외부 참고값과 비교 가능한 내부 기준 |
| 급감속 | −0.4g 이하 | 후보 사건 탐지 | 외부 참고값과 비교 가능한 내부 기준 |
| 영상–센서 동기 목표 | 33ms 이하 | 약 30fps 한 프레임 이내 | 설계 목표, 실측 결과 아님 |
| 페달–IMU 동기 목표 | 5ms 이하 | 센서 간 시각 정렬 | 설계 목표, 실측 결과 아님 |
| 프레임 결측 목표 | 1% 미만 | 수집 품질 | 설계 목표, 실측 결과 아님 |
| 반응성 최소 사건 | 5건 | 점수 표시 최소 표본 | 내부 가정 |
| Sync warning 가중치 | 0.5 | 품질 낮은 세션 영향 감소 | 내부 가정 |
| 점수 가중치 | 반응성 35·제동 25·페달 안전 25·부드러움 15 | 종합점수 구성 | 제품 초기 설정 |
| 파일럿 계획 | 운전자 20명·200시간·사건 1,000건 | 초기 재보정 계획 | 검증 완료 결과가 아닌 계획 |

## 7. 외부 연구·표준 참고값

외부 자료는 현재 PSI 수치의 직접 출처가 아니라, 내부 기준의 타당성을 검토할 때 비교하는 참고자료다.

| 참고값 | 자료의 조건과 의미 | PSI 적용 원칙 | 출처 |
|---|---|---|---|
| 0.60~0.65초 | 위험을 충분히 예상한 운전자의 중앙 제동 반응 | 예상 상황의 참고 범위로만 사용 | [2] |
| 약 1.15초 | 예상하지 못했지만 흔한 위험의 중앙 반응 | 선행차 제동 등 유사 조건에서만 참고 | [2] |
| 약 1.40초 | 완전한 돌발 상황의 중앙 반응 | 보행자 돌발 상황의 참고 범위로만 사용 | [2] |
| 평균 1.50초, SD 0.40초 | 실도로 장애물 대응에서 측정 가능한 제동 반응 운전자 56명 | 표본·상황이 다르므로 직접 점수화 금지 | [3] |
| 85백분위 1.90초 | 위 실도로 연구의 백분위 값 | 위험 경계가 아닌 분포 참고값 | [3] |
| 2.50초 | 대부분 운전자를 포괄하기 위한 정지시거 설계 반응시간 | 개인 운전자 점수 기준으로 사용 금지 | [4] |
| 0.35g | 정지시거 설계에 사용하는 차량 감속도 가정 | 급제동 판정 기준이 아님 | [4] |
| 종방향 ±0.45g | DriveCam 자연주행 연구의 영상 저장 트리거 | 사건 수집 기준의 비교자료 | [5] |
| −0.50g | 100-car 자연주행 연구의 강한 제동 탐지값 | PSI −0.4g의 비교자료, 보편 기준 아님 | [5] |

NHTSA는 반응시간이 기대 여부, 연령, 주의 부하, 피로, 시선 이탈, 날씨와 교통 조건 등에 따라 크게 달라 하나의 보편적인 반응시간을 정하기 어렵다고 설명한다.[1] 따라서 PSI는 외부 평균값 하나를 모든 운전자와 모든 상황에 적용해서는 안 된다.

## 8. 공식 출처

확인일은 2026년 11월 15일이다.

1. **NHTSA**, *Human Factors Design Guidance for Driver-Vehicle Interfaces*.
   https://www.nhtsa.gov/sites/nhtsa.gov/files/documents/812360_humanfactorsdesignguidance.pdf
   반응시간의 구성요소와 개인·상황별 변동성을 설명한다.

2. **NHTSA**, *Human Factors Insights for Collision Warning System Interfaces*.
   https://www.nhtsa.gov/sites/nhtsa.gov/files/cws_hf_insights_task_5_final_rpt.pdf
   예상, 비기대, 돌발 상황별 중앙 제동 반응시간을 정리한다.

3. **NHTSA**, *Development of an FCW Algorithm Evaluation Methodology With Evaluation of Three Alert Algorithms*.
   https://www.nhtsa.gov/sites/nhtsa.gov/files/dot20hs2081120145.pdf
   실도로 장애물 대응 연구의 평균, 표준편차와 백분위 반응시간을 정리한다.

4. **FHWA**, *Speed Concepts: Engineering and Technical Concepts*.
   https://highways.fhwa.dot.gov/safety/speed-management/speed-concepts-informational-guide/chapter-4-engineering-and-technical
   정지시거 설계의 2.5초 반응시간과 0.35g 감속도 가정을 설명한다.

5. **NHTSA**, *Age Versus Experience: Evaluation of Video Feedback Intervention for Newly Licensed Teen Drivers*.
   https://www.nhtsa.gov/sites/nhtsa.gov/files/documents/812508.pdf
   ±0.45g 종방향 트리거와 선행 100-car 연구의 −0.5g 강한 제동 기준을 설명한다.

6. **ISO**, *ISO 15623:2013 — Intelligent transport systems — Forward vehicle collision warning systems*.
   https://committee.iso.org/standard/56655.html?browse=tc
   전방 차량 충돌경고 시스템의 성능 요구사항과 시험 절차 범위를 확인하기 위한 표준이다. 본 보고서의 PSI 점수에는 ISO 수치를 직접 적용하지 않았다.

## 9. 현재 근거가 불충분한 표현

다음 표현은 실제 사용자 데이터와 자체 검증이 확보되기 전까지 제한해야 한다.

| 표현 | 문제 | 권장 표현 |
|---|---|---|
| “안전한 점수” | 사고·안전 결과와 점수의 연관성을 검증하지 않음 | “합성 데이터 기준 반응 점수” |
| “평균보다 빠름” | 실제 비교 코호트가 없음 | “현재 합성 사건 평균보다 빠름” |
| “강한 제동” | 60% 압력 등의 화면 구간은 제품 설명용 | “60% 이상 압력 구간” |
| “주의/양호” | 70·85점 구간의 외부 검증이 없음 | “초기 UI 분류” 또는 점수만 표시 |
| “동기화 ±5ms” | 아직 실측한 결과가 아니라 목표값 | “동기화 설계 목표 5ms 이하” |
| “수집률·배터리 상태” | 실기기 백엔드 미연결 | 숫자를 표시하지 않고 “미연동” |

## 10. 활성 화면에서 사용하지 않는 값

`apps/web/src/lib/sample-data.ts`에는 과거 화면 시안용 기간 점수, 기기 배터리, 주행거리와 날짜가 남아 있다. 현재 대시보드와 마이페이지는 이 파일을 가져오지 않으므로 활성 화면에 표시되지 않는다. 향후 실수로 재사용하지 않도록 삭제하거나 `deprecated` 디렉터리로 격리하는 것이 권장된다.

## 11. 재현 및 검증

```bash
PYTHONPATH=packages/signal/src:tools/synth/src \
  .venv/bin/python -m psi_synth.export_web \
  --out apps/web/src/lib/pedal-samples.json

.venv/bin/python -m pytest tests/test_web_samples.py
.venv/bin/python -m pytest
```

자동 테스트는 다음을 확인한다.

- 커밋된 JSON과 고정 시드 생성 결과의 일치
- 사건 ID 중복 여부와 시계열 길이
- T0~T7 마커 차이와 사건 지표의 일치
- T2·T4·T5·중첩 시점의 압력 정의
- 페달 사용 비율 합계
- 히스토그램 사건 수와 분석 범위
- 급가속·급감속 임계값과 예시 사건
- 데이터 원천, 시드, 설정 버전과 표본 간격 표기
- 웹 수치 근거 페이지의 계산값·내부 설정·외부 출처 분리

이 테스트는 **계산 재현성**을 검증한다. 실제 운전자 안전성, 사고 예측력, 임상적 또는 법적 타당성은 검증하지 않는다.

## 12. 자체 실증 후 추가해야 할 내용

실측 데이터가 확보되면 다음을 별도 버전의 보고서에 추가해야 한다.

1. 참여자 수, 주행 시간, 사건 수와 도로·날씨·속도 분포
2. T0~T7 수동 판독자 간 일치도와 센서 검출 오차
3. 장비별 동기화 RMS·최대오차·프레임 결측률
4. 연령·차종·도로 유형별 반응시간 분포와 신뢰구간
5. 점수 구간 결정 방법과 별도 검증 데이터 성능
6. 사고·위험 사건 결과와의 연관성 및 과적합 검토
7. 설정 버전 변경 이력과 이전 결과 재계산 정책

이 절차가 완료되기 전까지 PSI 점수는 운전 행동을 설명하는 연구·개발 지표로만 사용해야 한다.
