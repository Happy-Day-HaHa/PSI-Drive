# 화면 수치 근거표

현재 웹 화면의 분석 수치는 실제 운전자 기록이 아니라 `psi_synth`가 고정 시드로 만든 합성 세션의 정답값이다. 화면 시안을 위해 임의로 입력한 기간 비교 점수와 증감률은 대시보드에서 사용하지 않는다.

## 재현 방법

```bash
PYTHONPATH=packages/signal/src:tools/synth/src .venv/bin/python -m psi_synth.export_web --out apps/web/src/lib/pedal-samples.json
.venv/bin/python -m pytest tests/test_web_samples.py
```

테스트는 커밋된 JSON이 생성기 결과와 같은지, 사건 지표가 T0~T7 마커 차이와 일치하는지, 사용 비율의 합과 히스토그램 건수가 분석 범위와 일치하는지 확인한다.

## 수치별 근거

| 화면 수치 | 원천 | 산출 방식 | 해석 한계 |
|---|---|---|---|
| 세션·거리·주행 시간 | 합성 세션 6개 | 세션 수, 속도 적분 거리, 전체 지속시간 합계 | 실제 운행량 아님 |
| 급가속·급감속 횟수 | IMU 합성 신호 | 설정 v1의 `+0.3g`, `-0.4g` 기준을 넘는 구간 수 | 기준값은 제품 초기 설정 |
| 페달 사용 비율 | 가속·브레이크 합성 신호 | 차량 이동 중 가속/타력/제동/동시 입력 시간 비율 | 반올림으로 합계에 미세 오차 가능 |
| 반응·해제·전환·제동력 상승 시간 | 합성 정답 T0~T7 | 정의된 마커 간 정수 ms 차이의 평균 | 실제 영상 검출 오차가 포함되지 않음 |
| 압력·전환 히스토그램 | 합성 압력과 사건 지표 | 설정된 구간별 표본 또는 사건 수 집계 | 표본 수가 적어 모집단 해석 불가 |
| 사건별 반응 점수 | 설정 v1 점수 곡선 | 인지-해제, 페달 전환, 총 제동 반응의 곡선 환산점수 산술평균 | Phase 4 확정 전 임시 산식이며 안전도·과실을 뜻하지 않음 |

## 화면 표시 원칙

- 수치에는 합성 데이터임을 항상 표시한다.
- 사용자는 화면의 **수치 산출 근거**를 열어 생성 시드, 표본 간격, 설정 버전과 한계를 확인할 수 있다.
- 실측 데이터가 연결되기 전에는 외부 평균, 사고 감소율, 안전 향상률처럼 검증되지 않은 수치를 표시하지 않는다.
- 임계값이나 점수 곡선을 바꾸면 설정 버전을 올리고 JSON을 다시 생성한다.
