# PSI Studio Event Analysis v1

이 문서는 전방 카메라·풋웰 카메라·페달 센서·IMU를 공통 시간축으로 연결하기 위한 이벤트 계약이다. 현재 웹 데모는 합성 센서 데이터와 수동 마킹 시나리오를 사용하며, 실제 객체 탐지 결과나 실제 영상으로 오인되지 않도록 출처를 함께 표시한다.

## 1. 분류 체계

| 대분류 | 세부분류 | 필수 데이터 | 현재 상태 |
|---|---|---|---|
| 차량 움직임 | 일반 가속, 급가속, 지속 강가속, 급감속, 정지 직전 감속, 정지 후 급출발 | IMU, 속도, 페달 센서 | 급감속·일상 감속 합성 데이터 지원 |
| 페달 조작 | 가속 해제, 브레이크 접촉, 페달 전환, 제동력 상승, 페달 중첩, 반복 입력 | 페달 센서, 풋웰 영상 | 합성 데이터 지원 |
| 전방 상황 | 선행차 감속, 끼어들기, 보행자 출현, 교차로, 정체, 장애물 | 전방 영상, 객체 검출·추적 | 선행차·보행자 수동 마킹 시나리오만 지원 |
| 복합 이벤트 | 선행차 감속→제동, 보행자 출현→페달 전환, 끼어들기→급감속 | 전방 사건 + 페달 + IMU | 앞의 두 시나리오를 시간 순서로 연결 |

상위·하위 이벤트는 한 물리 사건을 중복 집계하지 않는다. 예를 들어 `급제동`은 `급감속`의 하위 태그로 저장하고 집계 기본 단위는 부모 이벤트 한 건으로 유지한다. 파생 태그는 필터와 분석에만 사용한다.

## 2. 이벤트 데이터 계약

```text
Event
├── id, session_id, parent_event_id
├── category, subtype, tags[]
├── start_ts_us, end_ts_us, duration_us
├── speed_start_mps, speed_end_mps
├── accel_peak_mps2, decel_peak_mps2, jerk_peak_mps3
├── accel_pedal_peak_pct, brake_pedal_peak_pct
├── transition_us, rise_us, overlap_us
├── front_clip, foot_clip
├── front_observations[]
├── related_event_ids[]
├── severity, detection_confidence
├── source_streams[], measured_fields[], estimated_fields[]
├── sync_quality, missing_fields[]
├── review_status, config_version
└── uncertainty_us
```

- 측정값은 센서 또는 프레임 타임스탬프에서 직접 얻은 값이다.
- 추정값은 객체 추적·거리 추정 등 모델 산출값이며 모델 버전과 신뢰도를 반드시 저장한다.
- 미수집 값은 `null`로 유지한다. 0 또는 임의의 샘플 값으로 대체하지 않는다.
- 임계값과 분류 규칙은 버전이 있는 설정 파일에서 관리한다.

## 3. 복합 이벤트 연결

1. 전방 사건의 최초 관측 시점과 불확실성을 기록한다.
2. 설정된 시간 창 안에서 가속 해제·발 이동·브레이크 접촉·IMU 감속 이벤트를 찾는다.
3. 스트림 동기화 품질이 기준을 통과한 경우에만 하나의 복합 이벤트로 연결한다.
4. 화면에는 `전방 사건 관측 → 가속 해제 → 발 이동 → 제동 시작 → 차량 감속` 순서를 표시한다.
5. 시간적 연관성은 운전자의 인지·의도 또는 사고 원인을 의미하지 않는다.

## 4. 전방 영상 분석 단계

- Phase 1: 분석가 수동 마킹과 센서 이벤트 연결
- Phase 2: 객체 검출(차량·보행자·자전거)과 다중 객체 추적
- Phase 3: 카메라 보정 후 상대 거리·상대 속도 추정 및 복합 이벤트 후보 생성
- Phase 4: 실제 주행 영상으로 오탐·미탐 검증 후 설명 가능한 인사이트 제공

차간거리와 충돌 가능성은 카메라 내·외부 파라미터, 렌즈 왜곡 보정, 차량 속도 및 추적 품질이 확보되기 전까지 표시하지 않는다.

## 5. 현재 웹 데모 범위

- 합성 페달·속도·감속도 시계열에서 지속 시간과 최대 Jerk를 계산한다.
- 보행자·선행차 장면은 실제 영상이 아닌 합성 시나리오 시각화다.
- 탐지 신뢰도와 실제 동기화 오차는 미산출로 표시한다.
- 전방 장면과 발·센서 시각화는 하나의 재생헤드로 함께 움직인다.
- 모바일에서는 고정된 시각화 영역 안에서 전방 장면과 발·센서 화면을 전환한다.
